# MGS Mod Kit 2.3.0

- Failed repairs restore the previous mod files and settings, including large
  audio files. A durable journal recovers interrupted runs without guessing
  whether a planned destination was an original file.
- Failed recovery retains snapshots and backups. Concurrent installers are
  blocked by a per-game operating-system lock.
- Better Audio payloads are confined to supported audio directories. Saves,
  recovery files and unrelated payloads cannot be installed from an audio pack.
- Custom settings survive repair independently for each game. Resetting to
  recommended settings is an explicit review-screen option. The pinned
  MGSHDFix schema is checked against upstream definitions, including a correction
  to the old pressure-overlay default.
- Installed content is verified before commit. Partial installs and removals
  list the result for each game, including required Steam restoration.
- Progress stays responsive during downloads/extraction, shows download bytes,
  retries transient failures and supports cancellation through recovery.
- Session logs persist with bounded retention. A cached notice points to newer
  kit releases while execution and mod downloads remain pinned and checksummed.
- Releases wait for Linux and Windows checks on the tagged commit. Installation,
  settings, audio and recovery instructions now have dedicated guides.

## Compatibility and upgrading

The mod pins remain MGSHDFix 4.1.0, MGSM2Fix v3.6, MGS2 Bugfix 3.0.0 and MGS3
Bugfix 2.0.1. Newer upstream releases were assessed in
[UPGRADE_ASSESSMENT.md](../UPGRADE_ASSESSMENT.md); a mod upgrade remains subject to
a matching configuration and real game boot validation. Old or damaged recovery
journals require the manual steps in [TROUBLESHOOTING.md](../TROUBLESHOOTING.md).

For large originals without permanent backups, removal requires Steam
verification. Kit 2.3.0 records their original hashes so a second removal run can
confirm restoration. Normal failure/cancellation restores temporary snapshots.
