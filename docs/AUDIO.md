# Better Audio

The Nexus author does not permit redistribution; download the files yourself:

| Game | File |
|:--|:--|
| [MGS2](https://www.nexusmods.com/metalgearsolid2mc/mods/3) | 2.0 Full or 2.0 Lite |
| [MGS3](https://www.nexusmods.com/metalgearsolid3mc/mods/4) | Main file (1.0), plus optional Update 2.0 |
| MGS3 ending | Optional HQ Ending Cutscenes; scenes may pause and need a button press |

Select each component independently. MGS3 installs in the order base → HQ ending
→ update when those components are selected together. You can add the update
later without reinstalling the base. Names may be changed; archive contents help
identify the game and role. Ambiguous roles require your confirmation.

The installer accepts `.sdt`, `.sdx` and `.xxs` payloads under `us/demo`,
`us/movie` and `us/vox`, plus MGS2's `us/demo2` and `us/movievr`. Top-level
text/Markdown/PDF documentation is skipped. An unrelated payload, save path,
game executable or installer recovery path rejects the whole archive before
any live game file is replaced. If a genuine future pack uses a new layout,
report its file listing rather than bypassing the check.

These user-supplied archives are not authenticated by the GitHub download pins.
Extraction and file sizes are verified; files up to 64 MiB are also hashed
before commit. Larger assets keep a temporary pre-run snapshot for rollback.
Permanent uninstall backups have a 64 MiB limit: see
[TROUBLESHOOTING.md](TROUBLESHOOTING.md) for restoring larger originals with Steam.
